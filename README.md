# T2T Hockey — public site (GitHub Pages)

Home page (English `index.html`, French `fr/index.html`, shared
`assets/site.css` and screenshots in `assets/screens/`), support and the
privacy policy for App Store Connect.

- Published from https://github.com/tap2track/tap2track.github.io
  → https://tap2track.github.io/ (support) and https://tap2track.github.io/privacy.html
  and https://tap2track.github.io/privacy-fr.html (French)
- `privacy.md` and `privacy-fr.md` must stay identical to
  `tap2track/Legal/PrivacyPolicy.md` and `PrivacyPolicy-fr.md` (the copies
  shown in the app). Unit tests check it.
- To update the site: copy this folder's files into the
  `tap2track.github.io` repository and push to `main`.
